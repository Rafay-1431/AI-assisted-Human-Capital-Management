# 🚀 HCM Lite

**HCM Lite** is a modern, BambooHR-inspired Human Capital Management system built for efficiency and fast delivery. It features robust role-based access control (RBAC), real-time database management via Supabase, visual analytics, and an integrated AI assistant.

---

## 🛠️ Tech Stack

- **Frontend & Framework:** Next.js (App Router, JavaScript, Tailwind CSS)
- **Database & Auth:** Supabase (PostgreSQL with Row Level Security / RLS policies)
- **State Management:** Redux Toolkit (RTK)
- **AI Integration:** Groq API via modular service abstraction

---

## 🌟 Core Modules

- **M1: Auth & Access:** Secure Supabase authentication with strict server-side role checks (Admin, HR, Employee).
- **M2: Organization Setup:** Department structuring, designations, and user management.
- **M3: Employee Directory:** Complete employee search, filters, and Employee 360 views.
- **M4: Attendance:** Web-based check-in/out and daily status tracking.
- **M6: Payroll Lite:** Salary structures, monthly runs, and net pay calculations.
- **M7: Dashboards & Analytics:** Real-time visual charts, KPI cards, and organizational metrics.
- **M8: AI Assistant:** Interactive AI chat powered by Groq for policy Q&A and system insights.
- **M9: Comms & Audit:** Announcements, notifications, and system audit logs.
